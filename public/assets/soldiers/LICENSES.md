# Soldier assets — licences
- `soldier.glb` — original work for this project (CC0 1.0). Built from:
  - Skeleton, base mannequin body and animations (Idle, Walk, Jog, Sprint, Crouch, Death01, Hit_Chest, Pistol_Idle):
    **Universal Animation Library (Standard)** by Quaternius — CC0 1.0. https://quaternius.com — mirror used:
    https://github.com/J-Ponzo/gltf-universal-animation-library
  - Uniform, helmet, headset, glasses, plate carrier, pouches, belt, pads, armbands, rifle, camo and PBR textures:
    modelled and baked procedurally by `src/soldiers/pipeline/*.py` (Blender 5.3 as a Python module). No third-party textures.
- `basis/basis_transcoder.{js,wasm}` — Basis Universal transcoder shipped with three.js (Apache-2.0, Binomial LLC).
